# CPD Certificate Generator

A browser-based bilingual CPD certificate generator based on the supplied CPD form and certificate design.

## Features
- School / institution name is entered by the user and appears throughout the certificate.
- Regional Office can be customized.
- English + Hindi participant and training fields.
- Participant / Resource Person selection.
- Upload a Principal signature image (PNG/JPG/WEBP) with instant preview.
- Remove uploaded signature to restore the default signature.
- Live certificate preview.
- Client-side PDF generation and printing.
- No server or database required.

## GitHub Pages
Upload all files to the repository root and enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.

The website works entirely in the browser; uploaded signatures are not sent to a server.
